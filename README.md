# 🌡️ Temperature Conversion Program

A simple Python program that converts temperatures between Celsius, Fahrenheit, and Kelvin.

## 📖 Description
This program allows the user to:
- Enter a temperature value
- Select the original unit (Celsius, Fahrenheit, or Kelvin)
- Automatically convert it into the other two temperature units

## 🚀 Features
- User input handling
- Conversion between all three temperature scales
- Clean and formatted output
- Simple and beginner-friendly code

## 🛠️ Technologies Used
- Python 3

2. Download or clone this repository.
